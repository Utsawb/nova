Detailed Description

A type-safe, heterogeneous key-value store.

This class stores values of different types associated with string keys. It manages the memory of the stored objects, allocating on insertion and deallocating when the store is destroyed or a value is overwritten. The templated add and get methods provide a type-safe interface for the end-user.

Example usage:

ParameterStore store;
store.add<int>("param1", 42);
int value = store.get<int>("param1");
